# 💸 UPI Transaction Analysis | Power BI

This project involves analyzing a UPI (Unified Payments Interface) transaction dataset to discover trends, user behavior, and other meaningful insights. Using Power BI, we performed data cleaning, preprocessing, and created interactive visualizations to better understand the transaction patterns and demographics involved.

## 📊 Project Overview

Unified Payments Interface (UPI) has revolutionized digital transactions in India. This analysis focuses on uncovering key trends and user behaviors by working with a UPI transaction dataset. The goal is to identify insights that can support decision-making, improve user engagement, and understand transaction volume across different user groups.

## 📁 Dataset

The dataset includes:
- Transaction details (amount, date, time, etc.)
- User demographics (age, gender, location)
- Mode of transaction
- Device/channel used for payment

*Note: The dataset used in this project is anonymized and for educational purposes only.*

## 🛠️ Tools & Technologies Used

- **Power BI** for data visualization and dashboard creation
- **Microsoft Excel / Power Query** for data cleaning and preprocessing
- **Data Analysis Techniques** including filtering, sorting, aggregating, and deriving new metrics

## 🔍 Key Steps Performed

- ✅ **Data Cleaning**: Removed null values, fixed data types, standardized fields for consistent analysis  
- 📐 **Preprocessing**: Grouped data, created calculated columns/measures to aid in deep analysis  
- 📊 **Visualization**: Built interactive dashboards showing:
  - Transaction volume over time
  - Demographics-based trends (gender, location, age group)
  - Popular UPI usage times and modes
- 📈 **Insights Generation**: 
  - Identified peak transaction times and high-usage age groups
  - Mapped location-wise usage patterns
  - Analyzed preferences for transaction types

## 📌 Key Insights

- Increased transaction volumes during specific times of the day
- Predominant user age groups making frequent transactions
- Urban areas showing higher UPI usage compared to rural regions
- Variation in transaction amount across different demographics
